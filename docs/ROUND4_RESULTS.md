# 第四轮结果：动态航路维护与运行验证

本轮交付是合成软件原型的完善，规则仍默认。动态窗口确实进入SIPP搜索，能在声明误差范围内利用移动设备留下的通行时间；它不能解除全时禁入规则，也没有获得原始SIPP的全部最优性/完备性保证。学习没有显示可靠优于固定强规则的收益，完整事件序列中动态方案还增加了计划反复修改。

## 2. 动态规划的收益与限制

动态模型把塔身持续物理占用、吊臂/吊索/吊物随时间变化的几何、持续作业禁入规则和误差保护分开。动态SIPP计算节点安全区间及**整个航段**的禁出发区间，窗口与世界/任务/规则/预约版本绑定；声明的空间/时刻误差进入保守时间管。缺失可靠误差界时退回完整包络。规划后仍经过独立时空复核。

可核算场景`examples/round4/dynamic_window.json`中，原定直行与吊索相撞；保守直行搜索无结果，动态直行等待约15.22秒后起飞、37.22秒结束并通过主检查与独立参考。可以绕行时，保守包络也可能迅速得到更稳定的绕行；全时禁入、始终占用、服务窗口/能量不足或等待资源不可用时，几何空隙不能自动成为允许通行条件。详细算法、误差、缓存和六类边界验证见动态规划说明及VALIDATION。

本轮修复了两项衔接错误：原任务能耗/服务等要求违规未加入repair；冻结前缀仍在地面时，新后缀改变未来起飞时刻却沿用旧起飞/等待元数据。还保持同机任务顺序并扩展完整飞行器链，避免把后续任务当作新的满电飞行器。调试中新增的候选内耗时导致同ID内容变化，也已移到诊断记录，并由完整候选内容确定身份。

## 3. 新序列评估协议及实际分母

旧round4初稿把同一基础拓扑的参数扰动当独立模板，已明确纠正并保留全部原结果，见`protocol-correction.json`。新主评估仅有**3个人工定义的不同父拓扑**，每父2个参数/事件变体，共6条完整序列，每序列4次到达事件决定，共24次决定、48次任务出现、12项唯一任务。它不是24个独立事件，也不是6个独立基础模板。

新父拓扑为折线双服务、双吊装交叉走廊、同机三起降点闭环。所有派生均在同一个test组；本轮不重训或调参，训练/验证/校准组均为0。完整输入清单在读取新测试结果前固定。高预算参考从两个不同父拓扑各选一个变体，共8次决定。新主测试不声称覆盖所有旧模式；共享等待容量及补证触发另有专项/参数诊断证据。

权重仍为round3的`synthetic-round3-a774ca1b9f04`，精细运动/同机/序列为训练范围外。敏感性实际改变检查顺序；GNN及ranker实际传入联合任务/动作顺序；全部必查项和硬约束不因此跳过。无边对照使用相同节点特征的旧已训练isolated网络。旧结束时间校准覆盖率不外推，没有新校准或新的安全概率。

每次决策共同2秒预算，包含约束、特征/推理、原计划检查和候选复核；已用模型开销从搜索剩余额度扣除，另限8顺序、32搜索、2500展开。候选超过截止才通过，不计入成功或采纳；强制检查少量跨过截止的实际超额也保留。补证会计、事务和导出在决策后另计，总运行时间如实报告。模型冷加载单列，不能把暖态比较误当冷启动。

## 4. 空闲条件纠错复现的主结果

以下来自固定源码v3的实际运行，整轮83.604秒，高预算参考10.018秒，均在配置预算内。第一次新拓扑测试与QA并行，且含候选耗时元数据问题，仍完整保留。纠错复现没有改变输入、模型、规则、候选集合或预算，不被称为新的未触碰测试。

“整序列成功”要求该序列4次决定均在预算内有完整联合维护候选；它不是全程实际飞行安全保证。“计划覆盖”累计成功决定中的完整任务集合。软件执行核查另列，不混用分母。

|---|---:|---:|---:|---:|---:|---:|
| 保守占用规则 | 3 | 16 | 31 | 5 | 2 / 0 | 10.686 |

保守方案还有4项已经结束但核查不合格、3项未到结束；动态各方案分别3项和5项。因此动态的维护候选覆盖提高不能被包装为实际执行完成更多。候选覆盖增加集中在同机闭环（7/8→8/8决定）及双施工点的动态规则（1/8→2/8）；折线双服务全部8/8。双施工点仍是明显困难案例，未删除。

所有主方案各执行776/776任务—约束pair检查，未检查比例0、未知几何pair数0；这批输入完整，不代表缺失信息时也能判定安全。无候选决定的机制为候选图/动作/窗口覆盖无结果和时间预算限制；分别保留，未标全局不可行。候选独立复核拒绝0。保守有3次决策跨截止合计约0.0020秒，动态规则8次合计约0.0102秒；强规则/学习/无边没有截止超额，没有晚完成候选被冒计成功。

首次找到完整可行方案平均时间只统计成功决定：保守0.1030秒（n=16）、动态规则0.2468秒（n=18）、强规则0.2984秒、学习0.2962秒、无边0.2942秒（后三者n=17）。失败并未从总体成功率和总耗时剔除。一次模型冷加载0.6578秒；学习总特征0.1521秒、推理0.0485秒，无边另有适配器加载0.0094秒。学习暖态总时间的微小差异不构成可靠收益；计入冷加载后学习约14.301秒，强规则约13.669秒。评价器共享一次图特征提取，Web端到端耗时不被声称与它相同。

## 6. 五个问题的结论

1. **未完成任务主要受什么影响？** 旧批次主要是未知几何、明确模型内能量/固定入场容量条件，以及遗漏任务要求的实现问题；新批次主要是双施工点候选覆盖与计算预算。未证明的失败仍保持未确定/有限搜索无结果。
2. **时变规划何时有收益？** 作业规则允许随运动开放、误差有界、合法等待及服务/能量余量足够时，可以利用通行窗口；持续禁入、缺失误差、资源争用或窗口过短时不能。动态更灵活也更耗计算，可能比保守绕行反复修改更多。
3. **学习是否超过固定强规则？** 没有可靠证据；完成、代价、重复修改相同，冷加载和推理需付开销，GNN无边对照也没有显示稳定额外贡献。规则继续默认。
4. **完整序列是否减少不必要调整？** 本批没有，动态方案重复修改4次，保守0次；不把单次可行候选数量当稳定性收益。
5. **哪些仅适用于合成仿真？** 全部结果，包括设备规则、运动误差、能耗、同机周转、补证到达、统计样本与软件执行指标。没有真实飞控、现场数据或现场效果验证。任意坐标转换、复杂摆动/三维动力学和多实例后置。
