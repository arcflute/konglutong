## 复制运行

```bash
cd /root/autodl-tmp/chengkong-zhihu
# 前后端同进程；新目录重演，原目录同版本重启恢复。
.venv/bin/chengkong serve --input examples/round4/dynamic_window.json \
  --db-dir runs/web-round4-A --host 127.0.0.1 --port 8765
.venv/bin/chengkong analyze --input examples/round4/dynamic_window.json \
  --planning-mode dynamic_windows --output runs/round4/reproduce-dynamic.json
.venv/bin/chengkong analyze --input examples/round4/dynamic_window.json \
  --planning-mode conservative --action-policy keep_detour --output runs/round4/reproduce-conservative.json
.venv/bin/python -m chengkong.imports examples/imports/construction_delay.json \
  --accept --output runs/round4/reproduce-material.json
```

自己电脑运行`ssh -N -L 8765:127.0.0.1:8765 -p <SSH端口> root@<服务器地址>`，打开`http://127.0.0.1:8765`。A/B/C逐步操作及浏览器自动演示见[ROUND4_DEMOS](ROUND4_DEMOS.md)；备份恢复命令见[RECOVERY](RECOVERY.md)。B/C使用`examples/park_crane_synthetic.json`与独立db-dir。已绑定模型的库重启不能省略对应模型；旧round2/3库不自动迁移，先备份并用新目录。

本轮运行对照命令与固定源码复现见ROUND4_RESULTS。本轮没有新训练产物；如要复现历史训练，README保留独立目录的round3训练/评估命令，禁止覆盖原权重。
