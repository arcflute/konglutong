# 实施计划

这是推荐的开发顺序，不是删减后的研究路线。所有核心方法都保留在功能清单里，分阶段完成；最初包仅有准备材料；各轮实际进展见本文件后文，不将阶段安排当作完成声明。

## P0：环境、依据与数据契约

读取 AGENTS 与项目文档；核对最终稿（如已提供）。检查磁盘挂载、系统与实际 Python/GPU/包版本，建立项目独立环境，记录 `docs/ENVIRONMENT.md`。不覆盖系统环境或预先安装所有 GPU 依赖。

根据实际条件确定技术栈。可优先考虑 Python 后端与算法、轻量持久化、浏览器前端；不把建议版本当作已经验证的依赖组合。几何、时空计算与可视化分离，先有可运行的计算流程。

创建 `docs/DATA_CONTRACTS.md`，定义对象、证据、变化事件、约束、任务、冲突、补证请求、候选和采纳反馈。首版坐标与单位遵循示例说明，时间与版本贯穿各模块。

完成条件：独立环境可用，输入可解析，模块边界清楚；原始文档和现有代码保留。

## P1：确定性端到端流程

实现参数化几何和场景关系、事件更新、语义规则到约束、保守候选筛选、连续航段冲突检查、延后/绕行候选、候选复核与用户采纳反馈。先用简单可核算图与规划方法打通流程，继续完成路线中的 SIPP。

至少跑通一项施工变化影响既有任务的示例；输出计算结果与证据，而不是写死前端答案。明确设备持续占用与活动占用，计划到期但未确认时保留未知。

完成条件：可重放同一输入并得到同一结果；能够指出冲突、生成条件化候选、拒绝过期候选。此阶段不将学习模块标记为已训练。

## P2：多任务、不完整信息与滚动维护

完成安全时间区间搜索、预约表与有限回溯、冲突导致的修复集合扩展、飞行器资源/任务条件复核。将第二层分析与第三层候选验证统一到同一契约。

实现两类补证触发（冲突敏感性、决策价值）的统一工作流，补证来源先用已知材料查询与明确标注的模拟服务。记录无证据、超时和预算耗尽。

完成条件：新航路引入的新关联也被复核；输入更新后旧候选失效；采纳操作原子更新计划与预约；没有证据时仍能明确返回条件或无法决策原因。

## P3：学习与多模态接入

逐项实现任务专用 XGBoost、GNN、修复排序模型的训练/推理和模型版本管理；建立情景生成、标签来源、完整事件划分和折外特征流程。校准使用独立数据，报告方法条件与有效范围。

接入真实 VLM/LLM 服务或选定本地模型，验证结构化输出、证据定位、失败降级和不确定字段处理。实际 API 或权重未准备好时保留禁用状态，继续完成不依赖它的工程工作。

完成条件：模型能在隔离的验证数据上运行，结果能与确定性基线比较；不得以接口存在、随机权重或训练集效果宣称方法有效。

## P4：界面、回放与竞赛材料

把场景、时间轴、施工变化、受影响任务、冲突证据、补证、方案对比、采纳和回放连到真实后端。初期允许简化二维/三维几何展示，避免被大规模城市模型下载阻塞。

补充对照和必要边界验证，记录结果与局限，完成启动、演示及数据来源说明。没有真实案例时展示合成场景，并保留明显标识。

## 阶段报告要求

每轮报告完成内容、对应功能 ID、执行过的命令与检查结果、未完成/未验证项及下一步。验证只覆盖本轮真实改动与具体风险，避免反复运行无关大规模测试。若用户明确限制本轮不运行，记录未验证状态，不编造通过结果。

### 本轮技术选择及依据

1. 保留Python单包及既有SIPP，新增协同编排、资源、在途上下文与独立参考模块，避免无理由重写可用底层。分段固定几何与线性飞行模型继续保留明确适用范围。
2. 增量按任务—约束对指纹复用；新几何仍扫描全任务，候选依赖不确定时扩大失效，联合资源全量检查。选择牺牲部分加速来避免仅凭旧关联漏检。
3. 转场是显式配置的合成地面搬运：距离/速度产生耗时，另计转场耗能、周转时间与补能；不把地面搬运伪装成已验证的空中转场，也不默认电池重置。
4. Web采用无需构建的HTML/SVG/JS与标准库HTTP，统一使用pipeline/SQLite后端。二维地图展示位置，另显示高度/时间；不改变后台三维约束。默认本地监听，不部署外网。
5. 学习用CPU轻量依赖，小GNN由NumPy实现可反传消息传播。数据可见特征与仿真真值分离，模板变体不跨组；各模型不读取上游拟合分数，因此当前无需折外预测。未来新增该依赖必须先实现折外或独立数据流程。
6. 单变量结束误差采用分位数与独立模板组残差校准，报告样本量、宽度和可交换假设；不将覆盖率套用到整条任务安全。规则默认，显式学习模式仅改变工作顺序，不能免检或自动采纳。
7. 真实多模态服务未配置时使用明确模拟响应及本地HTTP协议测试，继续完成其他工作。模型自报置信度不是校准概率，图片没有尺度/坐标依据时保持未知。
