实际问题和处理：

- 原敏感性模型在全部`check_task`完成后才执行，只影响补证顺序；本轮增加`priority_checks`，先排序再真实执行精算。预算未覆盖的pair保留`not_checked`，候选权威复核仍全量。
- 原GNN标签是直接影响加同一邻接的人工平滑。新标签改为实际几何冲突或联合资源/间距冲突成员，不再用邻居平均制造图模型优势；未观测到硬冲突不等同于未知信息安全。
- 原排序把真实代价相同的动作按字母再排不同relevance，新标签以1e-6精度成本并列。完整一次决策候选组保持在同一数据组。
- 原排序耗时未实测。本轮实际重复运行同一动作集合、约束和预算，报告全部query失败比例及共同成功集合代价/时间。
- 新数据初稿沿用静态局部求解，发现已起飞提案可能改写过去；在最终测试尚未评估时废弃该稿，完整保存到`round3-pretest-prefix-audit`。同一固定模板划分和配置重新标注；已起飞的局部delay/detour显式`unsupported_inflight_local_action`，在途实际效果由冻结前缀联合规划单独评价。这次重训不是按测试结果调参。
- 独立审阅检出合法ID包含冒号时，原`task:constraint`拼接会碰撞并漏掉检查。新增`pair_key`对任务ID中的百分号/冒号转义，round2/round3 runtime、数据标注和pipeline统一使用；普通现有样本ID不变，6项义务的手造反例现在执行6项。
- 旧校准有限样本次序计算本身正确。本轮保留组最大残差；当`ceil((n+1)(1-alpha))>n`时显式返回`insufficient_independent_groups`及无界策略，绝不截断成有限“保证”。

## 数据、划分及预算

先对6个独立模板实际测生成和标注，约0.04秒/事件，由此采用160个独立旋转布局/事件模板，每模板2个扰动，共320事件；每事件只有一个决策快照。`sequence_id`是来源索引，不能当作已实现多步时间序列训练。不同事件、扰动、快照不能替代独立模板数。

| 分组 | 独立模板 | 事件/决策快照 |
|---|---:|---:|
| 训练 | 80 | 160 |
| 验证 | 24 | 48 |
| 校准 | 32 | 64 |
| 最终测试 | 24 | 48 |

全量1122任务、4476任务—约束对、1122完整局部动作query。实际覆盖216个多施工点事件、178个共享起降点事件、129个活动几何未知事件、30个带冲突记录元数据的事件、52个有效/获取时间不同的记录事件、36个在途快照。**同机任务训练事件为0**；模式标签`pad_competition`不是强制资源冲突保证，以上统计来自实际world字段。迟到/冲突训练输入是单快照元数据，不声称训练了完整事件回放或材料冲突消解。

本语料的运动范围是保守静态外包络。新吊臂精细运动是训练域外；另用同一运动示例60/300/450秒的真实约束验证学习排序全量检查与规则分类一致，这3个相关快照不能记作3独立测试模板，也不是动态预测能力验证。

`protocol-frozen.json`在模型训练前固定全部父模板划分；worker只读train，选型只读validation。`selection-frozen.json`封存模型选择后才读取calibration和最终test。真实未来结束及几何真值单独放`simulator_truth.jsonl`，在线特征明确白名单不含ID、模式标签、成功、代价、实际结束、relevance或任何上游拟合预测。缺失掩码可见且不等于答案；缺失真值从不补成可通行证据。

每模型最多3组主要配置，本次XGB敏感性/排序各2组，分位数2种尺度方案，GNN同架构weighted/isolated各2随机种子，另训练同节点特征XGB对照。所有候选均只在验证集选择；GNN主种子预先固定，第二种子不替换主模型。单worker120秒，总训练上限3600秒；两次训练（含作废初稿）实测共42.92秒。标签每动作1秒/256展开，总生成上限900秒。无新大模型、GPU或系统驱动安装。

## 特征、结构和目标

- 敏感性：原可见包围盒/时间/来源/任务字段，增加航段到对象中心的二维最近距离、对象范围和高度、时段前后差。标签仍是声明尺寸/结束扰动的冲突比例；实际处理收益另以当前可见约束精算检出衡量。
- GNN：边区分共享起降、共享飞行器、时空走廊及共享保守约束，显式权重并对称度归一化；残差结构分开本节点和邻居通道，防止只剩邻居平均。节点含原始几何/时段/能量及显式关系度。邻接由可见信息生成，标签直接来自真实硬检查。相同特征无边消息网络、扰动/去边和节点XGB均保留。这里“无边”只移除消息传播邻接，节点仍保留共享资源度等可见关系汇总；它测试消息传播的增量价值，不能解释为完全无图信息对照。
- 排序：keep/delay/detour动作及求解前特征，标签来自有预算局部SIPP和约束复核。在线对联合动作仍取局部任务分数平均，不能当作已学到联合最优搜索。已执行任务不允许静态重排过去。
- 结束误差：双分位数（5%/95%），验证集比较未缩放和可见计划时长尺度；未缩放胜出。校准取每模板2变体的最大区间外残差，32组、alpha=.1、k=30。区间只作补证/暂缓建议，不把预测结束写成确认结束。

## 最终测试及对照结果

第一次最终评估保存在`evaluation.json`，后续冻结权重复现写独立`evaluation-reproduction-*.json`，不覆盖首次观察。以下统计主值来自首次评估，时间优化后的重现另列；同一测试已被观察，下一轮不能再称其完全未触碰。

| 指标 | 模型 | 对照/分母 |
|---|---:|---|
| 敏感性MSE | 0.0245462 | bbox 0.5389086；752对 |
| GNN NDCG主/第二种子 | 0.58731 / 0.60045 | bbox 0.53474；48图 |
| 无边同结构NDCG两种子 | 0.58050 / 0.57835 | 同节点特征XGB 0.56813 |
| 训练GNN推理时去边/扰动边 | 0.55914 / 0.56813 | 主模型原边0.58731 |
| 修复首选可行率 | 81/192=42.19% | keep首选59/192=30.73% |
| 两次求解预算完成局部任务 | 92/192=47.92% | keep→delay 59/192=30.73% |
| 全部三动作仍不可解 | 100/192=52.08% | 所有query保留，无全局不可行断言 |
| 共同成功59组平均代价 | 1.30633 | 规则相同；零变更原计划通过 |
| 结束误差事件覆盖 | 校准48/48=100% | 未校准43/48=89.58% |
| 两变体均覆盖的模板覆盖 | 校准24/24=100% | 未校准19/24=79.17% |
| 区间平均宽度 | 185.76秒 | 未校准108.78秒 |
| 校准宽度中位/P90/最大 | 197.20 / 210.98 / 214.89秒 | 32独立校准组 |

敏感性排序的实际50%pair预算检出关键pair比例96.08%，规则82.35%（共51关键pair）；但完整检查所有相关任务的比例只有1/48=2.08%，规则9/48=18.75%，因为学习顺序把预算分散到高分pair。19个有冲突事件的首个冲突平均检出1.07ms，规则0.59ms；48事件完整精算合计74.1ms，规则45.7ms。**MSE改善没有转化为更低端到端延迟或更高完整任务检查比例**。预算下两者未检查pair比例均50%，不会写成无冲突。

GNN相对bbox的模板配对NDCG差异均值0.05257，24模板bootstrap95%区间[0.0141,0.0944]。但相对同特征无边网络主/第二种子的差异区间分别[-0.0175,0.0343]和[-0.0014,0.0578]，包含0。48图中只有24图标签不全相同、18图全无正标签，因此同时报告有区分度子集，不通过删除零标签图美化总指标。**尚无稳定的邻接信息增益证据**。

排序当前批量推理保持原模型分数和顺序，减少重复预测调用。在独立复现中，全192query平均运行4.41ms（含2.26ms推理），规则0.93ms；共同成功59组平均4.46ms，规则0.79ms。求解次数平均1.578对1.693，但简单求解非常快，推理开销抵消次数收益。

重要的事后诊断：184/192query中keep与delay可行性相同，预注册keep→delay规则大量重复。**另外实际运行的简单keep→detour规则同样成功92/192**，平均2.42ms；冻结标签中固定detour首项84/192，亦高于学习81/192。因此学习对原弱规则的首选/预算收益不能称为可靠整体优越。此诊断明确标为posthoc，未替换原基线、未调模型、未改测试标签。

12个按固定test事件顺序选出的实际联合修复对照（来自6独立模板），规则/学习均5事件成功，完成14/44任务，选中计划稳定性向量逐项相同；学习增加开销，没有联合运行增益。局部query指标不能替代此联合结果。超时、预算耗尽、信息不足、有限图无结果分开记录，`global_infeasibility_proven=false`；未宣称对失败组作全局不可行证明。

校准宽度比round2小，但数据生成分布、独立数量和目标覆盖率都变了，不能直接称跨轮优化量。32校准组仍然少且重尾分布使区间扩张；单变量可交换组保证不等于轨迹或任务的联合安全概率。原建议统计混用了从`as_of`算的剩余时长与允许出发延后量，已在独立审计后修正：只针对第一个活动计算`max(0, planned_end + upper_error - task_departure)`，与`deadline-original_arrival`比较；已起飞任务只建议冻结前缀重规划。原评估保留，修正另存`calibration-impact-correction.json`。条件上允许延后58→50/192，需绕行/暂缓求解128→136，6项保持在途复核；区间超过余量而建议补证146→176。这些只是显式条件建议，未检查其他活动/资源，预测没有实际结束活动或自动生成可采纳等待计划。
